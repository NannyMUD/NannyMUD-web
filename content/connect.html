There are several ways to connect to NannyMUD and enter the game. The links below all explore various possibilities. Hopefully, one or more will work for you. Here is a check-list in case they don't:

  • Check that your machine has the necessary software.
  • Check that your machine is correctly configured.
  • Check that your software is correctly configured.
  • Read the FAQ; it might help.
  • Contact your system administration and/or vendor.

telnet mud.lysator.liu.se 2000 This requires that you have a working telnet program and that your browser has the correct configuration.

telnet 130.236.254.159 2000 This is the same as above, but with a specific IP-number. It can be useful if your network fails a DNS-lookup. This will then work, but the IP is likely to change and this link is unlikely to be updated.

http://mud.lysator.liu.se/java/Telnet/ This is a telnet client using Java. You don't need a telnet program to use this, but a browser that can handle Java 1.1.
